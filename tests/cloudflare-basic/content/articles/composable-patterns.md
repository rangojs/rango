excerpt: Design reusable building blocks for server component applications.
author: Docs Team
publishedAt: 2025-12-15
---

Composable patterns in RSC applications leverage the natural boundary between server and client components to create reusable abstractions. Server components can encapsulate data fetching and pass pre-processed props to client components that handle interactivity. This separation encourages building libraries of composable pieces that work across different routes and layouts without duplicating logic.
