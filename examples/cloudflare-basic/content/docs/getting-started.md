Welcome to Rango! This guide walks you through creating a new project, adding routes, and running the dev server.

## Installation

Create a new project with your package manager of choice and install the router package. The framework uses Vite under the hood so you get hot module replacement out of the box.

## Your First Route

Routes are defined using the `urls()` function which takes a builder callback. The builder receives helpers like `path`, `layout`, and `include` that you compose together.

## Running the Dev Server

Start the dev server and visit your app in the browser. Changes to server components are reflected immediately without a full page reload.
