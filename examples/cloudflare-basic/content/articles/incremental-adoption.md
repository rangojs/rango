---
title: Incremental Adoption of RSC
excerpt: Strategies for gradually introducing React Server Components into existing applications.
author: Docs Team
publishedAt: 2025-08-10
---

You do not need to rewrite your entire application to benefit from React Server Components. Start by identifying data-heavy pages that ship large client bundles and convert those to server components first. This incremental approach lets teams gain experience with the model while delivering measurable performance improvements early.
