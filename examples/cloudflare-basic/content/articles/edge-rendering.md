---
title: Edge Rendering
excerpt: Move your rendering closer to users with edge compute platforms.
author: Performance Team
publishedAt: 2025-06-15
---

Edge rendering deploys server-side logic to data centers distributed globally, reducing latency by processing requests near the user. Platforms like Cloudflare Workers enable this by running lightweight V8 isolates instead of full Node.js processes. When combined with RSC, edge rendering delivers server-rendered content with minimal round-trip overhead.
