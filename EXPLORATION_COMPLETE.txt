KEY INSIGHTS FOR host-router CREATION
================================================================================

1. NO BUILD STEP NEEDED
   Template: package.json
   {
     "main": "./src/index.ts",
     "module": "./src/index.ts",
     "types": "./src/index.ts",
     "exports": { ".": "./src/index.ts" },
     "files": ["src"]
   }
   Benefit: Simpler, faster iteration

2. COPY THESE FILES FROM rsc-router
   Direct copy (no changes):
     - tsconfig.json
     - .prettierrc
     - src/__tests__/setup.ts

   Copy and adapt:
     - eslint.config.js (review rules)
     - vitest.config.ts (update aliases)
     - playwright.config.ts (update paths)

   Use as template:
     - package.json (change name, adjust deps)

3. CREATE SOURCE STRUCTURE
   src/
   ├─ index.ts (barrel exports)
   ├─ types.ts (type definitions)
   ├─ core.ts (main functionality)
   ├─ utils.ts (helper functions)
   ├─ components.tsx (React components, if needed)
   └─ __tests__/
       ├─ setup.ts
       ├─ core.test.ts
       └─ utils.test.ts

4. ADD TESTS
   Unit tests (Vitest):
     - src/__tests__/*.test.ts
     - 80% coverage threshold
     - happy-dom environment

   E2E tests (Playwright):
     - tests/e2e/*.spec.ts
     - Critical paths
     - Runs against apps/web dev server

5. WORKSPACE INTEGRATION
   Update apps/web/package.json:
     "dependencies": {
       "host-router": "workspace:*"
     }

   Import in code:
     import { CoreFeature } from 'host-router'

COMMON MISTAKES TO AVOID
================================================================================

Build Script:
  ✗ WRONG: "build": "tsc"
  ✓ RIGHT: "type-check": "tsc --noEmit" (only)

Package Entry Points:
  ✗ WRONG: "main": "./dist/index.js"
  ✓ RIGHT: "main": "./src/index.ts"

Files to Include:
  ✗ WRONG: "files": ["src", "dist", "docs"]
  ✓ RIGHT: "files": ["src"]

Test Location:
  ✗ WRONG: "tests/" next to src/
  ✓ RIGHT: "src/__tests__/" inside src/

Workspace Reference:
  ✗ WRONG: "host-router": "^0.0.1"
  ✓ RIGHT: "host-router": "workspace:*"

ESLint Config:
  ✗ WRONG: Old .eslintrc.json format
  ✓ RIGHT: eslint.config.js (flat config)

TypeScript Target:
  ✗ WRONG: "target": "ES2015"
  ✓ RIGHT: "target": "ES2020"
