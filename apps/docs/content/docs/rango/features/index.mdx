Most features are just-in-time: the core is `urls()`, `path()`, `layout()`, `include()`, and `reverse()`. Caching, parallel routes, intercepts, prerendering, and the rest are opt-in — reach for them when a requirement appears, not up front.

## Pick a primitive

| I need to…                            | Use                             | Page                                                        |
| ------------------------------------- | ------------------------------- | ----------------------------------------------------------- |
| define URLs, layouts, and ownership   | the `urls()` tree               | [The Route Tree](/docs/rango/features/routing)              |
| link to a route without hardcoding it | `ctx.reverse()`, `useReverse()` | [Named Routes & Links](/docs/rango/features/named-routes)   |
| render data fresh on every request    | `loader()` + `useLoader()`      | [Loaders](/docs/rango/features/loaders)                     |
| gate or enrich requests               | `router.use()`, `middleware()`  | [Middleware](/docs/rango/features/middleware)               |
| cache a rendered subtree              | `cache()` on a segment          | [Caching & Revalidation](/docs/rango/features/caching)      |
| re-render a segment after an action   | `revalidate()`                  | [Caching & Revalidation](/docs/rango/features/caching)      |
| serve JSON/XML/streams from the tree  | `path.json()`, `path.stream()`… | [Response Routes](/docs/rango/features/response-routes)     |
| set titles, og tags, breadcrumbs      | the `Meta` handle               | [Metadata & Handles](/docs/rango/features/metadata)         |
| make navigation instant and safe      | `<Link prefetch>`               | [Navigation & Prefetching](/docs/rango/features/navigation) |
| test handlers without a server        | `renderHandler()`, `dispatch()` | [Testing](/docs/rango/features/testing)                     |
