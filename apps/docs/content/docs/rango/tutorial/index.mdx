In this tutorial you build **Brew**, a small storefront selling coffee gear. It runs as a single Cloudflare Worker: the router matches the URL, renders React Server Components, and streams HTML — and once the page is up, navigation happens client-side without full page loads.

The point of the tutorial is not the storefront. It's that by the end, you'll have touched every core idea in Rango once — routes declared in one tree, typed params, layouts, loaders, actions, revalidation, caching — each introduced when the app actually needs it.

## What you're building

Three pages and, in the later parts, a JSON endpoint:

| URL           | Route name | What it shows                           |
| ------------- | ---------- | --------------------------------------- |
| `/`           | `home`     | A landing page                          |
| `/shop`       | `shop`     | The product grid                        |
| `/shop/:slug` | `product`  | One product, or a 404 for unknown slugs |

The catalog is a hardcoded array — no database, no external services. Every snippet in this tutorial runs exactly as written, and you only need a Cloudflare account for the final deploy step.

By the end of part 3 the project looks like this; the later parts add loaders, actions, and the JSON endpoint to the same skeleton:

```
brew/
├── package.json
├── vite.config.ts
├── wrangler.json
└── src/
    ├── urls.tsx          # every route, in one tree
    ├── router.tsx        # createRouter()
    ├── document.tsx      # the <html> shell
    ├── worker.ts         # Cloudflare Worker entry
    ├── data.ts           # the hardcoded catalog
    ├── pages/
    │   ├── home.tsx
    │   ├── shop.tsx
    │   └── product.tsx
    ├── layouts/
    │   └── shop-layout.tsx
    └── components/
        └── shop-nav.tsx  # client nav with prefetching links
```

## Prerequisites

- **Node 20+**
- **pnpm**
- **A Cloudflare account** — only for the deploy at the very end of part 6. Everything before that runs locally.

You should be comfortable with React and TypeScript. You don't need prior experience with React Server Components or Cloudflare Workers; the tutorial explains what it uses as it goes.
