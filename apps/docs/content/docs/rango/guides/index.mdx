Each guide takes one requirement — "I need a modal", "I need dark mode", "I need to migrate from Next.js" — and shows the shortest correct path. They assume you know the basics from [Getting Started](/docs/rango/getting-started) and the [Features](/docs/rango/features) pages.

## Routing patterns

- [Layouts](/docs/rango/guides/layouts) — wrap child routes, share chrome, scope config
- [Parallel Routes](/docs/rango/guides/parallel-routes) — sidebars and multi-column layouts as named slots
- [Intercepting Routes](/docs/rango/guides/intercepting-routes) — modals and slide-overs on soft navigation
- [handler.use](/docs/rango/guides/handler-use) — attach default loaders and middleware to a handler
- [Host Router](/docs/rango/guides/host-router) — multi-app hosting with domain and subdomain patterns

## Data & mutations

- [Server Actions](/docs/rango/guides/server-actions) — mutations with `"use server"`, validation, and revalidation
- [use cache](/docs/rango/guides/use-cache) — function-level caching with the directive
- [Document Cache](/docs/rango/guides/document-cache) — edge caching with Cache-Control headers

## Advanced caching

- [PPR](/docs/rango/guides/ppr) — cached HTML shells with live holes
- [Prerender](/docs/rango/guides/prerender) — build-time rendering as a cache write
- [Shell Manifest](/docs/rango/guides/shell-manifest) — replayed handles feeding live loaders from a frozen shell

## Presentation

- [Theme](/docs/rango/guides/theme) — light/dark mode without a flash of the wrong theme
- [i18n](/docs/rango/guides/i18n) — locale routing and resolution chains
- [View Transitions](/docs/rango/guides/view-transitions) — animate layouts, routes, and slots
- [Breadcrumbs](/docs/rango/guides/breadcrumbs) — the built-in breadcrumb handle
